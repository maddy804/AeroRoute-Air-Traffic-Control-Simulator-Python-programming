04 / Algorithm Information

Dijkstra's Algorithm

Dijkstra's algorithm finds the shortest path between a source airport and a destination airport in a weighted graph with non-negative edge weights.

How it works:

1. Initialize the source distance to zero.
2. Select the unvisited airport with the smallest distance.
3. Update distances to its neighboring airports.
4. Repeat until the destination is reached.
5. Reconstruct the shortest route.

Academic simulation only. This website does not connect to live flight systems or provide real aviation navigation.
